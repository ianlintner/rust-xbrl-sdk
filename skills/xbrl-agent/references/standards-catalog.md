Source: [XBRL International, All Documents by Status](https://specifications.xbrl.org/specifications-full-index-by-status.html), retrieved 2026-10-26. This is a link catalog, **not** a copy of normative rules and **not** evidence that this SDK supports these specifications. Status and corrected errata can change; recheck the live index and a work product’s release history before implementation. Other status categories (drafts, notes, requirements, deprecated documents) are omitted, not declared irrelevant.

Use the linked full specification as normative authority and linked conformance suites as executable evidence. A suite link does not imply a pass. Record exact URI/version, clause, test case, expected result and current SDK status in an implementation PR.
