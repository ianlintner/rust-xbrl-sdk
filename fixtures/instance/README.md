# XBRL 2.1 instance extraction cases

Provenance: **authored** for this repository, derived from XBRL 2.1 Recommendation 2003-12-31 with errata through 2013-02-20, §§4.1–4.8, XML Namespaces 1.0 (3rd ed.), XML 1.0 (5th ed.), XML Schema Part 2: Datatypes (2nd ed., 2004-10-28) §§3.2.7, 3.2.9, 3.2.19, and the Appendix A instance schema. The 66 negative rows cover syntax, strict lexical dates/whitespace, ID uniqueness and unsupported constructs. Separate boundary tests cover resource limits. A separate positive stress test exercises 400 in-scope namespace declarations across 5,000 measures; this does not assert benchmark performance. `basic.xml` is not vendored. `invalid.tsv` embeds partial documents in an authored XBRL root and tests only the syntax/extraction boundary; it does not imply complete XBRL 2.1 conformance.

Official suite for **external smoke only**, not copied into this repository because the archive carries XBRL International's `All Rights Reserved` notice and no grant was established: https://www.xbrl.org/2025/XBRL-CONF-2025-07-16.zip (SHA-256 `00462b833fd064108d0781c601bf2b186db9b85ef950030df9db3ef2f68455e9`). The following official testcase variations informed expectations: `Common/300-instance/301-idScope.xml` V-1, `302-context.xml` V-01/V-03/V-07/V-08/V-09/V-10, `303-periodType.xml` V-01/V-02 (taxonomy periodType matching **not** tested), `304-unitOfMeasure.xml` (measure semantics **not** validated), `305-decimalPrecision.xml` V-01/V-02/V-04/V-05, `307-schemaRef.xml` V-1/V-3 (schema target validation **not** tested). No official conformance pass/fail count is asserted by this fixture set; the smoke test is extraction only.

`invalid.tsv`: `id<TAB>body XML<TAB>expected rule id`. The harness wraps body XML in an XBRL instance root with standard namespace declarations and a schemaRef; some cases supply a whole document via a separate test. The expected error IDs describe *parser* findings, never DTS/profile validity.
